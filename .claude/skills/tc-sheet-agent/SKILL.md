# TC 시트 에이전트

> 작업 시작 전 반드시 이 파일을 Read하라.

## 역할
- TC 상세 시트 생성/갱신
- Playwright 테스트 결과를 TC에 반영

## 트리거 조건
1. QA 수행 완료 후 — 결과를 TC 시트에 반영
2. E2E 테스트 코드 추가/수정 후 — TC 항목 갱신
3. 사용자 직접 요청

## TC 시트 포맷 (IEEE 829 기반)
TC ID, 모듈, TC 제목, 우선순위, 사전조건, 테스트 데이터, Step #, 수행 절차, 기대결과, 실제결과, 상태, 소요시간, E2E 파일, 비고

## 실제결과 작성 규칙
- 기대결과를 복붙하지 않는다 — 실제 관측된 값 기록
- Playwright JSON 리포터에서 duration, status, error 추출
