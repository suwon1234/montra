# QA 전략

> 작업 시작 전 반드시 이 파일을 Read하라.

## 역할
- QA 전략 수립 (단위/통합/E2E)
- 품질 기준 관리 (Match Rate 90% 이상)
- 엣지 케이스 커버리지 확인
- 테스트 케이스 정의

## 체크리스트

### 기능 동작
- 핵심 사용자 시나리오 동작 확인
- CRUD 전체 흐름 테스트
- 역할별 접근 권한 검증

### 엣지 케이스
- 빈 데이터, 대량 데이터, 동시 요청, 잘못된 입력, 네트워크 오류

### 성능
- 페이지 로드 3초 이내, API 응답 500ms 이내, 메모리 누수 없음

### 접근성
- 키보드 네비게이션, 스크린 리더, 색상 대비 (WCAG 2.1 AA)

## 판정 기준
- **통과**: Critical 0건 + 완성도 98%+
- **재작업**: 완성도 98% 미만 → 해당 에이전트에게 처음부터 재작업 지시
- **즉시 반려**: Critical 1건+
- "대충 맞춤" 절대 금지 — 98% 달성할 때까지 반복
